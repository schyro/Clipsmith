# Raw video to finished clips

Follow `AGENTS.md` at the repository root. It holds the full workflow:

- "When the user says they added videos to `Raw/`" for new recordings.
- "Music edits" when the user asks for edits or has put tracks in `Music/`.
- "Applying the user's review" when the user has reviewed clips in the editor.

Current output preferences are in `video_settings.json`.
